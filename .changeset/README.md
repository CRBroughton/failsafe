# Changesets

Hello and welcome! This folder has been automatically generated by
`@changesets/cli`, a build tool that works with multi-package
repos, or single-package repos to help you version and publish your code.
You can find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started engaging with this
tool:

## I am in a rush, what command do I run?

Run `pnpm changeset` in the root of your repo. This will ask you a few questions
and generate a file in the `.changeset` directory.

## What information do I need to provide?

You will need to provide the packages you would like to bump and the
bump type (patch/minor/major) you would like to bump them by. A summary
for the changeset is also required, as this will be used in the changelog.

## Can I write my own custom changelog entries?

Yes! When you run `pnpm changeset`, you can add a custom summary, which is
what gets written into `CHANGELOG.md` on `pnpm changeset version`.

## Can I select packages based on a customized list of glob patterns?

Yes! You can create a customized config to select the necessary directories
based on glob patterns.
